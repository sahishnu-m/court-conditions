# Pinned to minimum versions rather than exact ones (>= not ==).
#
# Exact pins would guarantee Streamlit Community Cloud installs precisely what
# was tested, but they also go stale and start failing to resolve. For a small
# personal project, minimums are the right trade: if a future release ever
# breaks something, change the >= to == on that one line to freeze it.

# Streamlit is PINNED rather than given a floor, which is the one exception to
# the note above.
#
# Streamlit Cloud serves its JavaScript in content-hashed chunks that the page
# loads lazily, so a chart or table only pulls its code when it is first drawn.
# Those filenames change with every Streamlit release. Left as ">=", a rebuild
# could quietly install a newer Streamlit, and any browser still holding the
# previous page would ask for chunk names that no longer exist and show
# "Failed to fetch dynamically imported module" where a chart should be.
#
# Pinning makes a rebuild of unchanged code produce byte-identical assets.
# Upgrade deliberately by raising this number and testing.
streamlit==1.64.0
pandas>=2.2
requests>=2.32

# Altair draws every chart. Streamlit renders Altair natively and applies the
# theme from .streamlit/config.toml to it, so the charts pick up the same
# palette and fonts as the rest of the page without being styled separately.
altair>=5.4

# requests-cache transparently stores API responses in a local SQLite file so
# repeated runs don't re-hit Open-Meteo. See court_conditions/cache.py.
requests-cache>=1.2

# astral computes sunrise/sunset from latitude and longitude locally.
# No API call, no key, works offline — it's pure astronomy.
astral>=3.2

# PyYAML reads config/courts.yaml and config/scoring.yaml.
PyYAML>=6.0
